## 🛠️ Troubleshooting Guide

Even well-built tools occasionally meet an unexpected environment. Below are the most common situations and how to approach them.

### The Installer Does Not Launch

Check whether your antivirus blocked execution. Some security suites flag system utilities by default. Add an exception for the installer, then retry.

### Permission Denied During Removal

Ensure you launched the application with administrator rights. Right-click the shortcut and choose the elevated launch option.

### A Program Reappears After Removal

Some applications are reinstalled by their own updater services. Disable the associated scheduled task or service before removing the parent program.

### The Trace Viewer Shows Unexpected Files

Files shared between multiple applications may appear. Review carefully and untick anything that belongs to software you intend to keep.

### The Interface Displays in the Wrong Language

Open settings and manually select your preferred language. The change applies immediately without a restart.

### Slow Scanning on Large Systems

Machines with thousands of installed entries take longer to index. Consider narrowing the scan scope or running the tool when the system is otherwise idle.

### Backup Files Accumulate

Removal backups are stored for safety. Periodically clear old backups from the settings area to reclaim space.

### Antivirus Interference During Removal

Temporarily pausing real-time protection during a large batch can prevent conflicts. Re-enable it immediately afterward.

### Portable Mode Does Not Retain Settings

Portable editions store configuration alongside the executable. Ensure the drive is writable and that you run the tool from the same location each time.
